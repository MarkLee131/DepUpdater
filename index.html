Run an analysis +

Complete the environment and database setup, then run from the DepUpdater directory with your project paths.

Analysis command
python MainProcess.py \
  --root /path/to/project \
  --module module-a \
  --output /path/to/new-run \
  --workers 2 \
  --analyzer-timeout 600

Use a new output directory outside your project. Check run.json and the analysis logs before applying candidate changes.
