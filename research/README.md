# Research records

`results/rq1`, `results/rq2`, and `results/rq3` contain the unchanged published
CSVs, renamed to lowercase filenames. See the
[result index and interpretation notes](../docs/research-results.md).

`baselines/dependabot.py` preserves the historical Dependabot evaluation script.
It assumes study-specific local paths and prepared inputs, and is not a
turnkey evaluation command. Use the
[original artifact](https://github.com/MarkLee131/DepUpdater/tree/163cf411da6047dbacb8340602314723d88b729b)
and its setup instructions when reproducing the paper.
